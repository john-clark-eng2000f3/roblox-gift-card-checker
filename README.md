# roblox-gift-card-checker

I buy gift cards in bulk and got tired of opening a browser for every code. This tool batch-checks them against Roblox's redemption endpoint and tells me what's still good.

## install

pip install -r requirements.txt

## usage

cat codes.txt | python check.py --token YOUR_ROBLOX_TOKEN
